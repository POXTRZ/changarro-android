# Changarro Android

Collaborative Android marketplace application built with Kotlin and Firebase.

The project was created as a university team project and combines authentication, marketplace features, user profiles, messaging and transaction history in a native Android application.

## Main features

- Email and password authentication with Firebase Authentication
- Google Sign-In
- User profiles stored in Cloud Firestore
- Product publishing with category, price, stock, description and image URL
- Product search and category filters
- Favorites
- Product detail view
- Contact with sellers through WhatsApp
- Internal chat between users
- Transaction history
- Events and notices
- Light and dark interface support

## Requirements

- Android Studio
- Android SDK 24 or higher
- Firebase Authentication
- Cloud Firestore
- Google Sign-In configuration

## Run locally

Clone the repository:

```bash
git clone https://github.com/POXTRZ/changarro-android.git
```

Open the project in Android Studio, configure Firebase, sync Gradle and run it on an emulator or Android device.
